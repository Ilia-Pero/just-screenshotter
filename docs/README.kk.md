Print Screen пернесін басып, аймақты белгілеңіз, үстіне сызып, скриншотты көшіріңіз, сақтаңыз немесе жіберіңіз. Сол аймақты бейнеге де жазуға болады. Скриншоттар арасында бағдарлама тек пернені күтеді: оның терезелері мен таймерлері жоқ, процессорды пайдаланбайды.

## Не істей алады

- Барлық мониторды түсіріп, үстінен редактор ашады.
- Қарындашпен, сызықпен, көрсеткімен, жақтаумен, маркермен сызады және мәтін жазады, сегіз түс бар.
- Сызылғанды өзгертеді: шерту белгіні таңдайды, содан кейін оны немесе ұштарын сүйреуге, қалыңдығы мен түсін өзгертуге, мәтінін қайта теруге немесе жоюға болады.
- Скриншотты көшіреді, PNG түрінде сақтайды немесе [серверіңізге](../server/README.md) жіберіп, сілтемесін көшіреді.
- Аймақты дыбысымен бейнеге жазады: Windows жүйесінде MP4, macOS жүйесінде MOV, Linux жүйесінде WebM. Компьютер дыбысы мен микрофонды жазу-жазбауды өзіңіз таңдайсыз; macOS 13 нұсқасына дейін тек микрофон. Жазуды «Тоқтату» түймесі, түсіру пернесі немесе трейдегі белгіше тоқтатады.
- 14 тілде сөйлейді. Тіл баптауларда таңдалады, ал оған дейін жүйе тілі қолданылады. Windows орнатқышында қазақ тілі жоқ.
- Өздігінен ешқайда ештеңе жібермейді: тіркелгі, телеметрия және жаңартуларды тексеру жоқ. Желі тек скриншотты сіз көрсеткен серверге жіберу үшін керек.

## Пернелер мен тінтуір

| Не істейді | Windows және Linux | macOS |
| --- | --- | --- |
| Аймақ скриншоты | Print Screen | ⌘⇧9 |
| Бүкіл экран скриншоты | Shift + Print Screen | — |
| Белсенді терезе скриншоты (Windows) | Alt + Print Screen | — |
| Аймақ бейнесі | Ctrl + Shift + Print Screen | ⌘⇧8 |

Басқа пернелер баптауларда таңдалады. Windows жүйесінде соның бәрін тінтуір түймелері де іске қосады: екеуі бірге, бөлек, Shift немесе Ctrl пернесімен. Бастапқыда бұл өшірулі: бағдарлама түймелерді бақылап тұрғанда, тінтуірдің әр қозғалысы процессордың 2 мкс шамасындағы уақытын алады, тыныш тұрғанда ештеңе алмайды. Wayland ортасында перне жүйе баптауларында тағайындалады.

## Редактордағы пернелер

| Перне | Не істейді |
| --- | --- |
| Ctrl+C | аймақты көшіреді |
| Ctrl+S | аймақты `Суреттер/Screenshots` қалтасына сақтайды |
| Ctrl+U | аймақты жібереді, сілтеме алмасу буферіне түседі |
| Ctrl+Z | соңғы сызылғанды болдырмайды |
| Delete | таңдалған белгіні жояды |
| Esc | редакторды жабады |

macOS жүйесінде Ctrl орнына ⌘ пернесі.

Шерту кез келген құралмен белгіні таңдайды. Екі рет шерту немесе Enter мәтінді өзгертеді. Тінтуір дөңгелегі қалыңдықты өзгертеді.

Қалғаны да баптауларда: бейнемен бірге не жазылатыны, қалта, тіл, жіберу және жүйемен бірге іске қосу. Соңғысы сіз өшіргенше қосулы тұрады. Баптаулар трейдегі белгіше мәзірінен немесе бағдарламаны `--settings` параметрімен іске қосқанда ашылады. Онсыз қайта іске қосу да скриншот жасайды.

## Firefox кеңейтуі

Беттің көрінетін бөлігін немесе бүкіл бетті түсіріп, сол редакторды жаңа қойындыда ашады: белгілеу, сызу, көшіру, сақтау. Пернелері: Alt+Shift+S және Alt+Shift+P. Бетке тек сіз сұрағанда қарайды, ешқайда ештеңе жібермейді және тек тілді есте сақтайды. Бейне жазбайды, скриншот биіктігі 32 000 пиксельге дейін.

## Қаншалықты жеңіл

2026 жылғы 24 қарашадағы өлшемдер, Windows Server 2022, экран 1920 × 1080, оңтайландырылған жинақ:

| Не өлшенді | Нәтиже |
| --- | --- |
| Тыныш тұрғандағы процессор | 10 секундта 0 мс |
| Тыныш тұрғандағы жады | алғашқы скриншотқа дейін 14 МБ, жетеуінен кейін 25 МБ |
| Тыныш тұрғандағы процестер | 1 |
| Перне басылғаннан редакторға дейін | жеті рет шақырғанда 0,61–0,75 с |
| Бағдарлама көлемі | 5,2 МБ |

Редактордың бұлай ұзақ ашылу себебі: терезесі әр скриншотта жасалып, одан кейін жойылады. Бұл тыныш тұрғандағы нөлдік жүктеменің бағасы.

Бейнені бөлек процесс жазады. Жазу аяқталғанда ол да аяқталып, бүкіл жадын жүйеге қайтарады. Бейнекартасы жоқ осы серверде 1920 × 1080 өлшемінде секундына 30 кадр процессордың бір ядросын және 207 МБ алады, 800 × 600 өлшемінде 0,4 ядро мен 78 МБ алады. H.264 кодтайтын бейнекарта бұл жұмысты өзіне алады; бұл әлі өлшенген жоқ.

GitHub бұл файлдарды осы репозиторийдің кодынан жинайды, әрқайсысын орнатып, бағдарламаны іске қосады, содан кейін ғана жариялайды. Файлдарда ақылы қолтаңба жоқ, сондықтан алғаш іске қосқанда Windows пен macOS ескертеді.

Бағдарламаны өзіңіз де жинай аласыз. Node.js 24 немесе жаңарақ нұсқасы және Rust керек, Windows жүйесінде тағы Microsoft C++ Build Tools, Ubuntu жүйесінде тағы `libwebkit2gtk-4.1-dev libayatana-appindicator3-dev librsvg2-dev libxdo-dev`.

```sh
git clone https://github.com/Ilia-Pero/just-screenshotter
cd just-screenshotter
npm ci
npm run tauri build
```

Орнатқыш `src-tauri/target/release/bundle` қалтасында пайда болады.
