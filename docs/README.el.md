Πατήστε Print Screen, επιλέξτε περιοχή, σχεδιάστε πάνω της και αντιγράψτε, αποθηκεύστε ή ανεβάστε την εικόνα. Ανάμεσα στα στιγμιότυπα το πρόγραμμα απλώς περιμένει το πλήκτρο: δεν έχει παράθυρα ούτε χρονόμετρα και δεν απασχολεί τον επεξεργαστή.

## Τι κάνει

- Παίρνει στιγμιότυπο όλων των οθονών και ανοίγει τον επεξεργαστή πάνω τους.
- Σχεδιάζει με μολύβι, γραμμή, βέλος, πλαίσιο, μαρκαδόρο και κείμενο σε οκτώ χρώματα.
- Αντιγράφει την εικόνα, την αποθηκεύει ως PNG ή την ανεβάζει στον [δικό σας διακομιστή](../server/README.md) και αντιγράφει τον σύνδεσμο.
- Μιλά 12 γλώσσες. Στην αρχή τη γλώσσα του συστήματος· άλλη επιλέγεται από το μενού.
- Δεν στέλνει τίποτα από μόνο του: δεν υπάρχει λογαριασμός, τηλεμετρία ή έλεγχος ενημερώσεων. Το δίκτυο χρησιμοποιείται μόνο για να ανέβει μια εικόνα στον διακομιστή που έχετε ορίσει.

## Πλήκτρα στον επεξεργαστή

| Πλήκτρο | Τι κάνει |
| --- | --- |
| Ctrl+C | αντιγράφει την περιοχή |
| Ctrl+S | αποθηκεύει την περιοχή στο `Εικόνες/Screenshots` |
| Ctrl+U | ανεβάζει την περιοχή, ο σύνδεσμος πάει στο πρόχειρο |
| Ctrl+Z | αναιρεί το τελευταίο σχέδιο |
| Esc | κλείνει τον επεξεργαστή |

Στο macOS, ⌘ αντί για Ctrl.

Στο μενού του εικονιδίου βρίσκονται η συντόμευση, ο φάκελος, η γλώσσα, η διεύθυνση του διακομιστή και η εκκίνηση με το σύστημα. Αν ξεκινήσετε το πρόγραμμα δεύτερη φορά, παίρνει επίσης στιγμιότυπο.

## Πόσο ελαφρύ είναι

Μετρήθηκε στις 24.11.2026 σε Windows Server 2022, οθόνη 1920 × 1080, βελτιστοποιημένη έκδοση:

| Τι | Αποτέλεσμα |
| --- | --- |
| Επεξεργαστής σε αδράνεια | 0 ms σε 10 s |
| Μνήμη σε αδράνεια | 14 MB πριν από το πρώτο στιγμιότυπο, 25 MB μετά από επτά |
| Διεργασίες σε αδράνεια | 1 |
| Από το πλήκτρο ως τον επεξεργαστή εικόνας | 0,61–0,75 s σε επτά εκτελέσεις |
| Μέγεθος προγράμματος | 5,0 MB |

Ο επεξεργαστής ανοίγει σε τόσο χρόνο επειδή το παράθυρό του δημιουργείται για κάθε στιγμιότυπο και καταστρέφεται μετά. Αυτό είναι το τίμημα του μηδενικού φόρτου σε αδράνεια.

## Κατάσταση

| Σύστημα | Κατάσταση |
| --- | --- |
| Windows | Λειτουργεί σε Windows Server 2022 με μία οθόνη. Δεν έχει δοκιμαστεί ακόμη σε Windows 10 και 11. |
| macOS 10.13+ | Μεταγλωττίζεται και περνά τις δοκιμές. Δεν το έχει εκτελέσει κανείς ακόμη. |
| Ubuntu 24.04+ | Μεταγλωττίζεται και περνά τις δοκιμές. Δεν το έχει εκτελέσει κανείς ακόμη. Σε Wayland ορίστε τη συντόμευση στις ρυθμίσεις πληκτρολογίου: η εντολή είναι `just-screenshotter`. |

## Εγκατάσταση

Δεν υπάρχουν ακόμη έτοιμα αρχεία, οπότε το πρόγραμμα πρέπει να μεταγλωττιστεί. Χρειάζονται Node.js 24 ή νεότερο και Rust, στα Windows επίσης Microsoft C++ Build Tools, στο Ubuntu επίσης `libwebkit2gtk-4.1-dev libayatana-appindicator3-dev librsvg2-dev libxdo-dev`.

```sh
git clone https://github.com/Ilia-Pero/just-screenshotter
cd just-screenshotter
npm ci
npm run tauri build
```

Το πρόγραμμα εγκατάστασης εμφανίζεται στο `src-tauri/target/release/bundle`. Δεν είναι υπογεγραμμένο, οπότε τα Windows και το macOS θα ρωτήσουν αν το εμπιστεύεστε.

## Μεταφράσεις

Οι μεταφράσεις είναι μηχανικές και δεν έχουν ελεγχθεί από φυσικούς ομιλητές. Αν δείτε λάθος, διορθώστε το στο `locales` ή στο `docs`.
