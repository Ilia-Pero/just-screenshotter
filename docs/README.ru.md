Just Screenshotter по-русски называется «Просто скриншотер».

![Редактор поверх пробного экрана: маркер, овал, стрелка и подпись](editor.png)

Нажмите Print Screen, выделите область, порисуйте на ней и скопируйте, сохраните или отправьте снимок. Ту же область можно записать на видео. Между снимками программа только ждёт клавишу: у неё нет окон и таймеров, процессор она не занимает.

## Что умеет

- Снимает все мониторы и открывает редактор поверх них.
- Рисует карандашом, линией, стрелкой, рамкой, овалом, маркером и пишет текст, восемь цветов.
- Меняет уже нарисованное: щелчок выбирает пометку, после этого её или её концы можно перетащить, задать толщину и цвет, перепечатать текст или удалить.
- Копирует снимок, сохраняет в PNG или отправляет на [ваш сервер](../server/README.md) и копирует ссылку.
- Записывает область на видео со звуком: MP4 на Windows, MOV на macOS, WebM на Linux. Писать ли звук компьютера и микрофон, выбираете вы; на macOS до 13-й версии только микрофон. Запись останавливают кнопка «Остановить», клавиша съёмки или значок в трее.
- Говорит на 14 языках. Язык выбирают в настройках и в установщике для Windows, а до выбора это язык системы.
- Сама ничего никуда не отправляет: нет учётной записи и телеметрии. Сеть нужна только для отправки снимка на сервер, который вы указали, и чтобы узнать о новой версии, когда вы нажмёте кнопку в настройках.

## Клавиши и мышь

| Что делает | Windows и Linux | macOS |
| --- | --- | --- |
| Скриншот области | Print Screen | ⌘⇧9 |
| Скриншот всего экрана | Shift + Print Screen | — |
| Скриншот активного окна (Windows) | Alt + Print Screen | — |
| Видео области | Ctrl + Shift + Print Screen | ⌘⇧8 |

Другие клавиши выбирают в настройках. На Windows то же самое запускают кнопки мыши: две сразу, отдельно, с Shift или с Ctrl. Сначала это выключено: пока программа следит за кнопками, каждое движение мыши занимает около 2 мкс процессорного времени, в покое ничего. На Wayland клавишу назначают в настройках системы.

## Клавиши в редакторе

| Клавиша | Что делает |
| --- | --- |
| Ctrl+C | копирует область |
| Ctrl+S | сохраняет область в `Изображения/Screenshots` |
| Ctrl+U | отправляет область, ссылка попадает в буфер обмена |
| Ctrl+Z | отменяет последний рисунок |
| Delete | удаляет выбранную пометку |
| Esc | закрывает редактор |

На macOS вместо Ctrl клавиша ⌘.

Щелчок выбирает пометку с любым инструментом. Двойной щелчок или Enter меняет текст. Колесо мыши меняет толщину.

В тексте Enter начинает новую строку, щелчок в другом месте или Esc заканчивает ввод. Колесо мыши меняет размер букв. Ошибки в русском и английском подчёркивает сама система, правая кнопка мыши предлагает исправление. С Shift рамка становится квадратом, а овал кругом.

Остальное тоже в настройках: что писать вместе с видео, папка, язык, отправка и запуск вместе с системой, который включён, пока вы его не выключите. Настройки открывают из меню значка в трее или запуском программы с `--settings`. Повторный запуск без него тоже делает снимок.

## Расширение для браузера

Для Firefox и для браузеров на Chromium: Chrome, Яндекс Браузер, Edge, Opera.

Снимает видимую часть страницы или страницу целиком и открывает тот же редактор в новой вкладке: выделить, нарисовать, скопировать, сохранить. Клавиши Alt+Shift+S и Alt+Shift+P. Смотрит на страницу, только когда вы попросите, никуда ничего не отправляет и помнит только язык. Видео не пишет, высота снимка до 32 000 пикселей.

## Насколько она лёгкая

Замеры 24.11.2026 на Windows Server 2022, экран 1920 × 1080, оптимизированная сборка:

| Что измеряли | Результат |
| --- | --- |
| Процессор в покое | 0 мс за 10 с |
| Память в покое | 14 МБ до первого снимка, 25 МБ после семи |
| Процессов в покое | 1 |
| От нажатия клавиши до редактора | 0,61–0,75 с в семи вызовах |
| Размер программы | 5,2 МБ |

Редактор открывается так долго, потому что его окно создаётся при каждом снимке и уничтожается после него. Это плата за нулевую нагрузку в покое.

Видео пишет отдельный процесс. Когда запись кончается, он завершается, и вся его память возвращается системе. На этом сервере, где видеокарты нет, 30 кадров в секунду при 1920 × 1080 занимают одно ядро процессора и 207 МБ, при 800 × 600 занимают 0,4 ядра и 78 МБ. Видеокарта, которая кодирует H.264, берёт эту работу на себя; это ещё не измеряли.

## Состояние

| Система | Что известно |
| --- | --- |
| Windows | Работает на Windows Server 2022 с одним монитором. Видео там тоже проверено, а запись звука с устройств нет: на сервере их нет. На Windows 10 и 11 ещё не проверяли. |
| macOS 10.13+ | Собирается, тесты проходят; на машине GitHub устанавливается, запускается и пишет экран со звуком компьютера. Руками её ещё никто не проверял. |
| Ubuntu 24.04+ | Собирается, тесты проходят; на машине GitHub устанавливается, запускается и пишет экран. На виртуальном экране X11 в Ubuntu 26.04 работают клавиши, выделение, сохранение и видео, на Wayland не проверяли. Руками её ещё никто не проверял. На Wayland клавишу назначают в настройках клавиатуры: команда `just-screenshotter`. |
| Firefox 128+ | Работает в Firefox 161, проверено без окна. Mozilla его ещё не подписала, поэтому после перезапуска Firefox его загружают заново. |
| Chrome, Яндекс Браузер, Edge, Opera | Работает в Edge 158, проверено без окна. Остальные не проверяли, нужен Chromium 120 или новее. |

## Установка

| Система | Файл | Как установить |
| --- | --- | --- |
| Windows 10 и 11 | [just-screenshotter-windows.exe](https://github.com/Ilia-Pero/just-screenshotter/releases/latest/download/just-screenshotter-windows.exe) | Запустите его. Если Windows не знает программу: «Подробнее», «Выполнить в любом случае». |
| macOS 10.13+ | [just-screenshotter-macos.dmg](https://github.com/Ilia-Pero/just-screenshotter/releases/latest/download/just-screenshotter-macos.dmg) | Перетащите программу в «Программы» и откройте. Когда macOS откажет, откройте системные настройки, «Конфиденциальность и безопасность», и нажмите «Подтвердить вход». |
| Ubuntu 24.04+ | [just-screenshotter-ubuntu.deb](https://github.com/Ilia-Pero/just-screenshotter/releases/latest/download/just-screenshotter-ubuntu.deb) | `sudo apt install ./just-screenshotter-ubuntu.deb` |
| Firefox 128+ | [just-screenshotter-firefox.zip](https://github.com/Ilia-Pero/just-screenshotter/releases/latest/download/just-screenshotter-firefox.zip) | Откройте `about:debugging`, «Этот Firefox», «Загрузить временное дополнение» и выберите файл. После перезапуска Firefox загрузите его снова. |
| Chrome, Яндекс Браузер, Edge, Opera | [just-screenshotter-chrome.zip](https://github.com/Ilia-Pero/just-screenshotter/releases/latest/download/just-screenshotter-chrome.zip) | Распакуйте, откройте `chrome://extensions`, включите «Режим разработчика», нажмите «Загрузить распакованное расширение» и выберите папку; папку не удаляйте. Яндекс Браузер доверяет только каталогам и может выключить расширение. |

GitHub собирает эти файлы из кода этого репозитория, устанавливает каждый, запускает программу и только потом публикует. Платной подписи у файлов нет, поэтому при первом запуске Windows и macOS предупреждают.

Программу можно собрать и самому. Понадобятся Node.js 24 или новее и Rust, на Windows ещё Microsoft C++ Build Tools, на Ubuntu ещё `libwebkit2gtk-4.1-dev libayatana-appindicator3-dev librsvg2-dev libxdo-dev`.

```sh
git clone https://github.com/Ilia-Pero/just-screenshotter
cd just-screenshotter
npm ci
npm run tauri build
```

Установщик появится в `src-tauri/target/release/bundle`.
