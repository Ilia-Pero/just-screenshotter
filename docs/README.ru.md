Английское название программы: Just Screenshotter.

По клавише Print Screen программа снимает все мониторы и открывает поверх экрана редактор. В нём выделяют область, рисуют на ней, а затем копируют, сохраняют или отправляют снимок. Ту же область можно записать на видео.

Между снимками в памяти остаётся один процесс со значком в трее. На тестовой машине он занимал 14–25 МБ памяти и 0 мс процессорного времени за 10 секунд ([замеры](#замеры)).

## Установка

| Система | Файл | Как установить |
| --- | --- | --- |
| Windows 10 и 11 | [just-screenshotter-windows.exe](https://github.com/Ilia-Pero/just-screenshotter/releases/latest/download/just-screenshotter-windows.exe) | Запустите файл. Если Windows покажет предупреждение, нажмите «Подробнее», затем «Выполнить в любом случае». |
| macOS 10.13 и новее | [just-screenshotter-macos.dmg](https://github.com/Ilia-Pero/just-screenshotter/releases/latest/download/just-screenshotter-macos.dmg) | Перетащите программу в «Программы» и откройте. После первого отказа macOS откройте системные настройки, «Конфиденциальность и безопасность», и нажмите «Подтвердить вход». |
| Ubuntu 24.04 и новее | [just-screenshotter-ubuntu.deb](https://github.com/Ilia-Pero/just-screenshotter/releases/latest/download/just-screenshotter-ubuntu.deb) | `sudo apt install ./just-screenshotter-ubuntu.deb` |
| Firefox 128 и новее | [just-screenshotter-firefox.zip](https://github.com/Ilia-Pero/just-screenshotter/releases/latest/download/just-screenshotter-firefox.zip) | Откройте `about:debugging`, «Этот Firefox», «Загрузить временное дополнение» и выберите файл. При закрытии Firefox удаляет такое расширение, после перезапуска его загружают снова. |
| Chrome, Edge, Opera, Яндекс Браузер | [just-screenshotter-chrome.zip](https://github.com/Ilia-Pero/just-screenshotter/releases/latest/download/just-screenshotter-chrome.zip) | Распакуйте архив в папку, которую не будете удалять. Откройте `chrome://extensions`, включите «Режим разработчика», нажмите «Загрузить распакованное расширение» и выберите папку. Яндекс Браузер может выключить расширение, установленное не из магазина. |

Windows и macOS предупреждают о файлах, потому что у них нет платной подписи. GitHub собирает файлы из этого репозитория, устанавливает программы на чистых машинах и запускает их. Только после этого выпуск публикуется.

## Возможности

- Рисование карандашом, линией, стрелкой, рамкой, овалом, маркером и текст: восемь цветов, толщина от 1 до 72 пикселей.
- Правка нарисованного в любой момент. По щелчку пометку можно передвинуть, потянуть за концы, перекрасить, перепечатать её текст или удалить.
- Копирование, сохранение в PNG и отправка на [ваш сервер](../server/README.md): ссылка попадает в буфер обмена.
- Запись выделенной области со звуком компьютера и микрофоном: MP4 на Windows, MOV на macOS, WebM на Linux. До macOS 13 записывается только микрофон. Запись останавливают кнопка «Остановить», клавиша съёмки или значок в трее.
- 14 языков. В настройках также задают папку для файлов, клавиши и запуск вместе с системой, он включён с самого начала.

## Клавиши

| Действие | Windows и Linux | macOS |
| --- | --- | --- |
| Скриншот области | Print Screen | ⌘⇧9 |
| Скриншот всего экрана | Shift + Print Screen | не задан |
| Скриншот активного окна, только Windows | Alt + Print Screen | |
| Видео области | Ctrl + Shift + Print Screen | ⌘⇧8 |

Клавиши меняют в настройках. Настройки открываются из меню значка в трее или командой `just-screenshotter --settings`. На Wayland клавишами распоряжается рабочий стол: добавьте в настройках клавиатуры сочетание с командой `just-screenshotter`.

На Windows те же действия можно запускать двумя кнопками мыши, нажатыми одновременно, без клавиш или вместе с Shift или Ctrl. По умолчанию это выключено: пока программа следит за кнопками, каждое движение мыши занимает около 2 мкс процессорного времени.

В редакторе (на macOS вместо Ctrl клавиша ⌘):

| Клавиша | Действие |
| --- | --- |
| Ctrl+C | копирует область |
| Ctrl+S | сохраняет область в `Изображения/Screenshots` |
| Ctrl+U | отправляет область и копирует ссылку |
| Ctrl+Z | отменяет последнее изменение |
| Delete | удаляет выбранную пометку |
| Колесо мыши | меняет толщину линии или размер букв |
| Shift | делает рамку квадратной, а овал круглым |
| Enter | открывает выбранный текст для правки; при вводе начинает новую строку |
| Esc | заканчивает ввод, в остальных случаях закрывает редактор |

Двойной щелчок тоже открывает текст для правки. Ошибки в русском и английском подчёркивает проверка орфографии самой системы.

## Расширение для браузера

Расширение снимает видимую часть страницы (Alt+Shift+S) или страницу целиком (Alt+Shift+P) и открывает тот же редактор в новой вкладке. В один снимок помещается до 32 000 пикселей страницы по высоте. Расширение работает в Firefox и в браузерах на Chromium; видео оно не записывает.

## Данные и сеть

Снимки и записи хранятся на вашем компьютере. Программа обращается к сети в двух случаях: когда вы отправляете снимок на указанный вами сервер и когда нажимаете «Проверить обновления». Учётной записи и телеметрии в ней нет. Расширение обращается к странице после нажатия его кнопки или клавиш и сетевых запросов не делает.

## Замеры

Windows Server 2022, один монитор 1920 × 1080, без видеокарты, оптимизированная сборка, 24.11.2026.

| Что измеряли | Результат |
| --- | --- |
| Процессорное время в покое | 0 мс за 10 с |
| Память в покое | 14 МБ до первого снимка, 25 МБ после семи |
| Процессов в покое | 1 |
| От нажатия клавиши до редактора | 0,61–0,75 с в семи запусках |
| Размер файла программы | 5,2 МБ |
| Запись 1920 × 1080, 30 кадров в секунду | 1 ядро процессора, 207 МБ |
| Запись 800 × 600, 30 кадров в секунду | 0,4 ядра, 78 МБ |

Окно редактора создаётся для каждого снимка и после него уничтожается, отсюда время открытия. Видео пишет отдельный процесс, который завершается вместе с записью. Запись на машине с аппаратным кодировщиком H.264 не измеряли.

## Сборка

Понадобятся Node.js 24 или новее и Rust, на Windows ещё Microsoft C++ Build Tools, на Ubuntu ещё `libwebkit2gtk-4.1-dev libayatana-appindicator3-dev librsvg2-dev libxdo-dev`.

```sh
git clone https://github.com/Ilia-Pero/just-screenshotter
cd just-screenshotter
npm ci
npm run tauri build
```

Установщик появится в `src-tauri/target/release/bundle`. Тесты, устройство кода и правила изменений описаны в [CONTRIBUTING.md](../CONTRIBUTING.md).

## Переводы

Основные языки: русский и английский. Остальные двенадцать переведены машиной, носители языка их не проверяли. Исправления вносят в `locales` и `docs`.
