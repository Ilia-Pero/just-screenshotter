![Ο επεξεργαστής πάνω από δοκιμαστική οθόνη: μαρκαδόρος, πλαίσιο, βέλος και κείμενο](editor.png)

Πατήστε Print Screen, επιλέξτε περιοχή, σχεδιάστε πάνω της και αντιγράψτε, αποθηκεύστε ή ανεβάστε την εικόνα, ή εγγράψτε την περιοχή σε βίντεο. Ανάμεσα στα στιγμιότυπα το πρόγραμμα απλώς περιμένει το πλήκτρο: δεν έχει παράθυρα ούτε χρονόμετρα και δεν απασχολεί τον επεξεργαστή.

## Τι κάνει

- Παίρνει στιγμιότυπο όλων των οθονών και ανοίγει τον επεξεργαστή πάνω τους.
- Σχεδιάζει με μολύβι, γραμμή, βέλος, πλαίσιο, μαρκαδόρο και κείμενο σε οκτώ χρώματα.
- Αλλάζει ό,τι έχει ήδη σχεδιαστεί: ένα κλικ επιλέγει ένα σημάδι και μετά σύρετε το ίδιο ή τα άκρα του, αλλάζετε πάχος και χρώμα, ξαναγράφετε το κείμενο ή το διαγράφετε.
- Αντιγράφει την εικόνα, την αποθηκεύει ως PNG ή την ανεβάζει στον [δικό σας διακομιστή](../server/README.md) και αντιγράφει τον σύνδεσμο.
- Εγγράφει την περιοχή σε βίντεο με ήχο: MP4 στα Windows, MOV στο macOS, WebM στο Linux. Εσείς επιλέγετε αν θα εγγραφεί ο ήχος του υπολογιστή και το μικρόφωνο· στο macOS προς το παρόν μόνο το μικρόφωνο. Η εγγραφή τελειώνει με το κουμπί «Διακοπή», τη συντόμευση ή το εικονίδιο.
- Μιλά 12 γλώσσες. Η γλώσσα επιλέγεται στον επεξεργαστή, στο μενού του εικονιδίου και στο πρόγραμμα εγκατάστασης για Windows· μέχρι τότε είναι η γλώσσα του συστήματος.
- Δεν στέλνει τίποτα από μόνο του: δεν υπάρχει λογαριασμός, τηλεμετρία ή έλεγχος ενημερώσεων. Το δίκτυο χρησιμοποιείται μόνο για να ανέβει μια εικόνα στον διακομιστή που έχετε ορίσει.

## Πλήκτρα στον επεξεργαστή

| Πλήκτρο | Τι κάνει |
| --- | --- |
| Ctrl+C | αντιγράφει την περιοχή |
| Ctrl+S | αποθηκεύει την περιοχή στο `Εικόνες/Screenshots` |
| Ctrl+U | ανεβάζει την περιοχή, ο σύνδεσμος πάει στο πρόχειρο |
| Ctrl+Z | αναιρεί το τελευταίο σχέδιο |
| Delete | διαγράφει το επιλεγμένο σημάδι |
| Esc | κλείνει τον επεξεργαστή |

Στο macOS, ⌘ αντί για Ctrl.

Τα σημάδια επιλέγονται όταν δεν είναι ενεργό κανένα εργαλείο. Το διπλό κλικ ή το Enter αλλάζει το κείμενο. Ο τροχός του ποντικιού αλλάζει το πάχος.

Στο μενού του εικονιδίου βρίσκονται η συντόμευση, ο φάκελος, η γλώσσα, η διεύθυνση του διακομιστή και η εκκίνηση με το σύστημα. Αν ξεκινήσετε το πρόγραμμα δεύτερη φορά, παίρνει επίσης στιγμιότυπο.

## Πόσο ελαφρύ είναι

Μετρήθηκε στις 24.11.2026 σε Windows Server 2022, οθόνη 1920 × 1080, βελτιστοποιημένη έκδοση:

| Τι | Αποτέλεσμα |
| --- | --- |
| Επεξεργαστής σε αδράνεια | 0 ms σε 10 s |
| Μνήμη σε αδράνεια | 14 MB πριν από το πρώτο στιγμιότυπο, 25 MB μετά από επτά |
| Διεργασίες σε αδράνεια | 1 |
| Από το πλήκτρο ως τον επεξεργαστή εικόνας | 0,61–0,75 s σε επτά εκτελέσεις |
| Μέγεθος προγράμματος | 5,2 MB |

Ο επεξεργαστής ανοίγει σε τόσο χρόνο επειδή το παράθυρό του δημιουργείται για κάθε στιγμιότυπο και καταστρέφεται μετά. Αυτό είναι το τίμημα του μηδενικού φόρτου σε αδράνεια.

Το βίντεο το γράφει ξεχωριστή διεργασία, που τερματίζεται μαζί με όλη τη μνήμη της όταν τελειώσει η εγγραφή. Σε αυτόν τον διακομιστή, χωρίς κάρτα γραφικών, 30 καρέ το δευτερόλεπτο σε 1920 × 1080 απασχολούν έναν πυρήνα και 207 MB, σε 800 × 600 το 0,4 ενός πυρήνα και 78 MB. Μια κάρτα γραφικών που κωδικοποιεί H.264 αναλαμβάνει αυτή τη δουλειά· αυτό δεν έχει μετρηθεί ακόμη.

## Κατάσταση

| Σύστημα | Κατάσταση |
| --- | --- |
| Windows | Λειτουργεί σε Windows Server 2022 με μία οθόνη. Εκεί έχει δοκιμαστεί και το βίντεο· η εγγραφή ήχου από συσκευές όχι, επειδή ο διακομιστής δεν έχει. Δεν έχει δοκιμαστεί ακόμη σε Windows 10 και 11. |
| macOS 10.13+ | Μεταγλωττίζεται και περνά τις δοκιμές· σε μηχάνημα του GitHub εγκαθίσταται, εκκινεί και γράφει την οθόνη. Κανείς δεν το έχει δοκιμάσει με το χέρι ακόμη. |
| Ubuntu 24.04+ | Μεταγλωττίζεται και περνά τις δοκιμές· σε μηχάνημα του GitHub εγκαθίσταται, εκκινεί και γράφει την οθόνη. Κανείς δεν το έχει δοκιμάσει με το χέρι ακόμη. Σε Wayland ορίστε τη συντόμευση στις ρυθμίσεις πληκτρολογίου: η εντολή είναι `just-screenshotter`. |

## Εγκατάσταση

| Σύστημα | Αρχείο | Πώς εγκαθίσταται |
| --- | --- | --- |
| Windows 10 και 11 | [just-screenshotter-windows.exe](https://github.com/Ilia-Pero/just-screenshotter/releases/latest/download/just-screenshotter-windows.exe) | Εκτελέστε το. Αν τα Windows δεν γνωρίζουν το πρόγραμμα: «Περισσότερες πληροφορίες», «Εκτέλεση ούτως ή άλλως». |
| macOS 10.13+ | [just-screenshotter-macos.dmg](https://github.com/Ilia-Pero/just-screenshotter/releases/latest/download/just-screenshotter-macos.dmg) | Σύρετε το πρόγραμμα στις Εφαρμογές και ανοίξτε το. Όταν το macOS αρνηθεί, πηγαίνετε στις Ρυθμίσεις συστήματος, «Απόρρητο και ασφάλεια», και πατήστε «Άνοιγμα οπωσδήποτε». |
| Ubuntu 24.04+ | [just-screenshotter-ubuntu.deb](https://github.com/Ilia-Pero/just-screenshotter/releases/latest/download/just-screenshotter-ubuntu.deb) | `sudo apt install ./just-screenshotter-ubuntu.deb` |

Το GitHub μεταγλωττίζει αυτά τα αρχεία από τον κώδικα αυτού του αποθετηρίου, εγκαθιστά το καθένα, εκκινεί το πρόγραμμα και μόνο τότε τα δημοσιεύει. Δεν έχουν υπογραφή επί πληρωμή, γι’ αυτό τα Windows και το macOS προειδοποιούν στην πρώτη εκκίνηση.

Μπορείτε και να μεταγλωττίσετε το πρόγραμμα μόνοι σας. Χρειάζονται Node.js 24 ή νεότερο και Rust, στα Windows επίσης Microsoft C++ Build Tools, στο Ubuntu επίσης `libwebkit2gtk-4.1-dev libayatana-appindicator3-dev librsvg2-dev libxdo-dev`.

```sh
git clone https://github.com/Ilia-Pero/just-screenshotter
cd just-screenshotter
npm ci
npm run tauri build
```

Το πρόγραμμα εγκατάστασης εμφανίζεται στο `src-tauri/target/release/bundle`.
